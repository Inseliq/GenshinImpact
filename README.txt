GENSHIN IMPACT — фанатский лендинг
==================================

Структура:
  index.html          — структура страницы, секции и ссылки
  style.css           — все стили (Flexbox / display: flex)
  images/             — все иллюстрации локально в формате WebP

Запуск:
  Просто откройте index.html в любом современном браузере.
  Интернет для фотографий и оформления не требуется.

Секции:
  1. Главный экран
  2. Об игре (три карточки)
  3. Регионы Тейвата
  4. Популярные персонажи
  5. Галерея
  6. Финальный баннер и Footer

Адаптация:
  Есть варианты для ПК, планшетов и телефонов.
  Мобильное меню работает без JavaScript (HTML details).

Иллюстрации нарезаны из макета, созданного нейросетью в этом чате.
Это учебный фанатский проект, неофициальный сайт HoYoverse.
